# Número Secreto

Projeto utilizado durante o curso de Git e GitHub da Alura.

## 📚 Sobre o projeto

O código-base deste projeto foi disponibilizado pela Alura e utilizado como material de estudo durante o curso.

O objetivo deste repositório é praticar conceitos de Git e GitHub, como:

- Criação e gerenciamento de repositórios
- Commits e histórico de versões
- Push e pull
- Clonagem de repositórios
- Resolução de conflitos
- Revert e reset
- Alteração de commits
- Colaboração utilizando GitHub
